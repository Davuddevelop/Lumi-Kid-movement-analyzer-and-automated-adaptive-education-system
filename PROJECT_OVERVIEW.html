LUMIAI
A screen-free coding playground where kids program a real robot with physical colored blocks 🤖
Ages 5–8 Computer Vision Adaptive Learning Physical Robot

The Big Idea

Lumi teaches algorithmic thinking through physical play instead of a keyboard. Children arrange colored blocks on a mat, a camera reads them, and a robot car drives the exact path they "programmed" — making abstract concepts like sequencing, loops, and debugging tangible and fun.

Technical Stack

Backend Hub

server.py

FastAPI + WebSocket — broadcasts live game state to every client.

Vision

color_detector.py

OpenCV HSV detection, sorts blocks left-to-right into commands.

Robot

robot_controller.py

Serial F/L/R commands to ESP32/Arduino, with a software simulator fallback.

AI Brain

lumi_ai.py

BFS path-planning + Claude chatbot for tutoring and auto-solve.

Frontend

dashboard/ (React + Vite)

Kid-facing UI: animated grid, robot, blocks & the LET'S GO! button.

Levels

level_system.py

Progressively harder missions with obstacles and goals.
