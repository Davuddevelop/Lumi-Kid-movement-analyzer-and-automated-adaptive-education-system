What Lumi Is

Lumi teaches children algorithmic thinking through physical play — no keyboard, no screen-staring. Kids arrange colored blocks on a mat, a camera reads the sequence, and a real robot car drives the exact path they "programmed." Mistakes become visible and fixable, turning sequencing, loops and debugging into a hands-on game guided by a friendly AI tutor.

How It's Deployed

Frontend

Vercel

React dashboard + a serverless /api/chat so the AI tutor works even with no Python backend. Also supports a full software-only browser demo (client-side BFS animates the robot).

Backend

Render

FastAPI + WebSocket server, holds the ANTHROPIC_API_KEY, runs levels, vision intake, AI and analytics.

Hardware

ESP32 Robot

Connects over 2.4GHz WiFi via secure WebSocket (wss:443) to the server, registers itself, and executes missions with encoder precision.
